CARA MENJALANKAN APLIKASI KASIR

1. Install XAMPP.
2. Jalankan Apache dan MySQL.
3. Salin folder kasir_app ke:
   C:\xampp\htdocs\kasir_app
4. Buka http://localhost/phpmyadmin
5. Buat/import database.sql.
6. Buka:
   http://localhost/kasir_app
7. Login:
   Username: admin
   Password: admin123

FITUR:
- Login/logout
- Dashboard
- CRUD produk
- Transaksi penjualan
- Pengurangan stok otomatis
- Perhitungan total, pembayaran, kembalian
- Cetak struk
- Laporan penjualan
